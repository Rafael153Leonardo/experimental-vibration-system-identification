# Data Policy

This repository is designed for public sharing.

Do not commit:

- full raw development folders;
- third-party, university-owned or lab-private files;
- unpublished measurements without permission;
- trained model checkpoints such as `.pth` or `.pt`;
- personal files, screenshots, or local IDE metadata.

Allowed public material:

- synthetic signals;
- real sample CSVs from this home-built project;
- real figures generated from this project;
- code written for this public implementation;
- citations and references to papers, without redistributing copyrighted PDFs.

Recommended wording for public data:

```text
This project uses real measurements from a home-built vibration experiment and
synthetic signals for reproducibility checks.
```
