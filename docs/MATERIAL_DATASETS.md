# Material Dataset Notes

The original project tree contains material information mainly through folder
names and analysis comments, not through CSV columns. The public repository keeps
only curated samples, so the material context is stored as metadata.

## Original Dataset Groups

| Original group | Interpreted material/context | Evidence in original workspace | Public sample |
| --- | --- | --- | --- |
| `Dataset_sensor/inox` | inox ruler / stainless-steel ruler | folder name, `forcado.py` comment "Regua de Inox - Duffing", `nova_hip.py` uses `PASTA_ACOPLADO = 'Dataset_sensor/inox'` | `data/sample/sample_inox_raw_calibrated.csv` |
| `Resultados_Finais_Sincronizados` | synchronized inox runs | derived synchronized files from the inox pipeline | `data/sample/sample_inox_synchronized.csv` |

| `Dataset_sensor/acoplado` | coupled setup | scripts refer to hidden/coupled dynamics | not copied publicly yet |

The FFT audit in `docs/RAW_FFT_AUDIT.md` found that the inox raw and processed
folders are frequency-consistent around `4.98 Hz`. The main folder-name issue is
`inox_centralizado`: it was generated by `centralizar_dados.py` from
`Dataset_sensor/vibracao`, not from `Dataset_sensor/inox`.

## Classification Rule

Material classification should only be treated as valid when the trial has:

- known material/context;
- free cantilever length;
- beam thickness;
- beam width if reporting section properties;
- density or a justified density interval;
- extracted natural frequency.

Rows with missing geometry are still useful for frequency extraction and
repetition statistics, but they must not be converted into a Young modulus with
default dimensions from another material.

## Inox Ruler Geometry

The user-provided product image of the inox ruler gives the nominal full-ruler
dimensions:

```text
length_m = 0.30
width_m = 0.025
thickness_m = 0.001
```

The actual experimental setup used an added paper target at the tip:

```text
paper_height_m = 0.035
paper_width_m = 0.025
paper_thickness_m = 0.0003
```

The public material-study metadata now records the final, micrometer-verified
geometry for the inox rows:

```text
length_m = 0.300
width_m = 0.025
thickness_m = 0.00055   # micrometer reading; the "1 mm" marking is nominal
density_kg_m3 = 7850
```

With this geometry and the ensemble frequency (`4.982 Hz`), the inverse
Euler-Bernoulli calculation gives `E = 205.3 GPa`, inside the stainless/carbon
steel range.

**Historical note (provenance of the old 17.6 GPa figure):** the original
exploratory analysis used effective values recalled from the experiment —
`length_m = 0.270`, `width_m = 0.020`, `thickness_m = 0.00150`, `f ≈ 4.976 Hz`,
no tip-mass correction — which yield `E ≈ 17.6 GPa`. That number is **not**
reproducible with the current pipeline defaults: with the corrected length
(`0.300 m`) the same wrong thickness gives `≈ 27 GPa`, and the edge-photo
thickness (`1.0 mm`) gives `≈ 61 GPa`. See `docs/ORIGINAL_CODE_AUDIT.md` for
the full course correction (forced-mode clamp check + micrometer).
